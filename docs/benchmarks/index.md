# Benchmarks

The internal benchmark harness is not included in the current v2 release.

The previous benchmark suite targeted the v1 execution architecture and was
removed rather than carried forward as an incompatible baseline. Performance
benchmarking for the v2 executor and planning architecture will be revisited
separately.

Historical v1 results should not be treated as performance baselines for v2.

For now, clifra's v2 release focuses on API semantics, correctness, autograd,
compilation, and device support rather than published performance claims.
